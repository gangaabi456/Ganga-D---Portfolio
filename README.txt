Ganga D Portfolio - static version (no browser editing)

Open index.html. All content is in content.js. All design is in style.css. Behaviour is in app.js.
Keep every file and folder together.

1. Pictures: copy your files into the images folder with the names listed in images/README.txt.
2. Text, project links, skills, certificates: edit content.js, then save and refresh the browser.
3. Resume: put the PDF in the files folder and set resume:"files/resume.pdf" in content.js.
4. Contact form: set endpoint:"https://..." in content.js (Formspree or Web3Forms form URL).
   Until then it says "not sent" and shows your email link.
5. Put it online: upload the whole folder to Netlify, Vercel or GitHub Pages.
